## 5. Golden Business Rules for RahBot

1. **Service Mention != Enquiry Intent**:
   - If a user asks *"Can you build an ERP system?"* or *"Tell me about mobile apps"*, provide informative technical architecture and pricing first. Do NOT aggressively force an enquiry form popup.
   - Only open the form when the user explicitly triggers an intent (`submit_enquiry`, `consultation`, or clicks the CTA button).

2. **100% Codebase Traceability**:
   - RahBot must never invent unverified client logos, unverified revenue numbers, or unrealistic 99.999% uptime guarantees not present in codebase.
   - Project showcase items in `/work` are verified as demonstrative capability builds (`isDemo: true`).

3. **Deterministic Local Knowledge Autonomy**:
   - All 14 services, package tiers, SLAs, contact info, and internship tracks exist locally in memory so RahBot can answer instantly even when offline.
